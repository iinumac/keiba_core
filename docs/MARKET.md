# 市場を上回れているか

## 検証の手順

1. **市場の情報を一切使わないモデル**で3着内確率を推定する
2. **市場の見立てと比較**する（単勝オッズ → Harville → 3着内確率）
3. **市場が過小評価している馬**を買って、実際の払戻で回収率を測る

市場由来の特徴量を使ったモデルで「市場との差」を測っても意味がない。
差が出にくいよう作られてしまうため。`stages.MARKET_FREE_FEATURES` は
オッズ・人気とその派生に加え、`prev_odds` と `prev_popularity`
（前走とはいえ市場の評価）も外してある。

検証期間は2025〜2026年の 5,882レース / 81,132頭。払戻は実データ。

---

## 1. 市場フリーのモデル

| | AUC |
|---|---|
| 市場フリー（16特徴量） | 0.7417 |
| **市場フリー ＋ 走破タイム・上がり（23特徴量）** | **0.7527** |
| 市場込み（20特徴量） | 0.8212 |
| 市場込み ＋ 走破タイム・上がり | 0.8209 |
| **単勝オッズ単独** | **0.8189** |

**走破タイムと上がりを足すと市場フリーモデルは +0.0110 改善する。**
`r3_time_z`（直近3走のタイム偏差）は `prev_finish` を上回る最重要特徴量になった。

ところが**市場込みモデルには効かない**（0.8212 → 0.8209）。
つまり **市場は既にタイムと上がりを織り込んでいる。**

**単勝オッズ1本だけで AUC 0.819。** 我々のモデルは市場に及ばない。
市場は調教・厩舎の動き・当日の気配まで織り込んでいるので当然ではある。

### 走破タイム・上がりを足しても市場は超えられない

| 市場フリーモデルの特徴量（上位） | AUC低下 |
|---|---|
| **r3_time_z**（直近3走のタイム偏差） | **0.0329** |
| prev_finish（前走着順） | 0.0300 |
| level_score | 0.0186 |
| age | 0.0101 |
| horse_prev_top3_rate | 0.0088 |
| **best_last_3f**（過去最速の上がり） | **0.0088** |

単独では強力だが、市場込みモデルに足しても改善しない。
同じオッズ帯での回収率にも差が出ず、value で絞っても
全頭（71.6%）を安定して上回らない（上位1%で82.5%、区間67〜98）。

## 2. 市場の見立てとのズレ

Harville で単勝オッズから3着内確率を出し、実測と比べる。

| 市場の見込み | 実測 | |
|---|---|---|
| 0.040 | **0.052** | 人気薄を過小評価 |
| 0.146 | 0.178 | |
| 0.548 | 0.486 | |
| 0.815 | **0.737** | 本命を過大評価 |

一見すると「人気薄に妙味がある」ように読める。**が、これは早計。**
Harville は独立性を仮定するため、人気薄の複勝確率を過小に見積もる癖がある。
市場の誤りと変換の癖が混ざっているので、実際の払戻で確かめる必要がある。

## 3. 実際の払戻で検証

### 複勝を全頭買ったときの回収率（単勝オッズ帯別）

| オッズ帯 | 頭数 | 的中率 | 回収率 |
|---|---|---|---|
| 〜2倍 | 1,396 | 83.0% | **91.8%** |
| 2〜4 | 6,676 | 61.4% | 85.1% |
| 4〜7 | 9,275 | 43.8% | 81.6% |
| 7〜12 | 9,493 | 30.3% | 77.3% |
| 12〜20 | 9,632 | 22.6% | 81.2% |
| 20〜40 | 12,260 | 14.2% | 78.7% |
| 40〜100 | 14,436 | 7.1% | 71.6% |
| 100倍〜 | 17,964 | 2.0% | **46.6%** |

**人気馬ほど回収率が高い。** 複勝における本命・大穴バイアスは、
穴狙いに不利な方向に働いている。Harville の示唆とは逆の結論。

### AIが市場より高く見た馬を買う

| 条件 | 頭数 | 的中率 | 回収率 |
|---|---|---|---|
| value 上位50% | 40,566 | 11.3% | 67.8% |
| value 上位10% | 8,114 | 14.5% | 72.9% |
| value 上位5% | 4,057 | 15.7% | 76.6% |
| **ratio 上位10%** | 8,114 | 2.5% | **53.5%** |
| **ratio 上位1%** | 812 | 0.6% | **44.7%** |

**全体平均（約78%）より悪い。** モデルが「市場が過小評価している」と
判断した馬は、実際には市場の方が正しかった。

比（`ratio`）で絞ると人気薄ばかりを拾い、回収率は44.7%まで落ちる。
**穴狙いは逆効果。**

### 決定的な検証：同じオッズ帯の中でAIは識別できているか

市場が同じ評価をしている馬の中で、AIの確率で上下に分ける。

| オッズ帯 | AI | 的中率 | 回収率 |
|---|---|---|---|
| 〜4倍 | 上位 | **68.6%** | 86.5% |
| | 下位 | 61.7% | 86.0% |
| 7〜12 | 上位 | **31.8%** | 78.1% |
| | 下位 | 28.8% | 76.5% |
| 20〜40 | 上位 | **14.9%** | 79.6% |
| | 下位 | 13.6% | 77.8% |

**的中率は一貫してAI上位が高い。モデルには識別力がある。**
ところが**回収率には差が出ない**（4〜7倍帯では下位の方が高い）。

つまり **AIが「来る」と見た馬は実際に来やすいが、その分だけ配当も低い**。
市場は的中率の差をちょうど正しく価格付けしている。

## 4. 市場の過剰反応 — はじめて見つかった有意な歪み

ここまでは「市場が知らない情報」を探していたが、**市場が知っていて
値付けを誤っている**ところを探すと、統計的に有意な歪みが見つかった。

市場は**直近の目立った結果に引きずられる**。同じ人気帯の平均回収率との差:

| 前走 | 超過pt | |
|---|---|---|
| 13番人気以下 × 14着以下 | **−10.9pt** | ▲過大評価 |
| 13番人気以下 × 2-3着（**人気薄で激走**） | **−6.6pt** | ▲過大評価 |
| 1番人気 × 9-13着（**1番人気で大敗**） | **−5.9pt** | ▲過大評価 |
| 4-6番人気 × 9-13着（地味に凡走） | **+3.9pt** | ◯過小評価 |
| 7-12番人気 × 9-13着 | **+2.9pt** | ◯過小評価 |
| 4-6番人気 × 4-8着 | **+2.3pt** | ◯過小評価 |

**良くも悪くも目立った馬は次走で過大評価され、地味に負けた馬は過小評価される。**
典型的な recency bias。

### 同じバイアスは他の軸でも出る

| 軸 | 条件 | 超過pt | |
|---|---|---|---|
| **休み明け** | 1年以上 | **−20.3pt** | ▲ |
| | 6〜12か月 | −8.1pt | ▲ |
| | 3週以内（詰めすぎ） | −1.7pt | ▲ |
| | **6〜8週** | **+3.8pt** | ◯ |
| | 9〜12週 | +3.0pt | ◯ |
| **前走の着差** | 5馬身以上の大敗 | **−10.5pt** | ▲ |
| | 2〜3馬身差 | −1.7pt | ▲ |
| | **クビ・ハナ差負け** | **+2.0pt** | ◯ |
| **連続性** | **2走連続勝利** | **−8.5pt** | ▲ |
| | 3走連続3着内 | −3.8pt | ▲ |
| | 2走連続3着内 | −3.6pt | ▲ |
| | 3走とも着外 | +1.1pt | ◯ |
| **乗り替わり** | 継続騎乗 | −1.7pt | ▲ |
| | 乗り替わり | +1.0pt | ◯ |
| | 格上騎手へ | +0.4pt | （有意差なし） |

**一貫している。良くも悪くも目立った馬は過大評価され、地味な馬は
過小評価される。** 連勝中・大敗直後・長期休養明けはいずれも買われすぎ。

なお「有名騎手への乗り替わりは買われすぎ」という通説は、複勝では
確認できなかった（+0.4pt、有意差なし）。意外にも**継続騎乗の方が
買われすぎ**（−1.7pt）。

### 実用的な効果

これらを合わせた「過大評価」集団の複勝回収率は **67.1%**（全体74.5%）。
除外すると全体が **76.4%（+1.9pt）** に上がる。

逆に「適度な間隔（6〜12週）× 惜敗または地味な凡走」を満たす
「過小評価」集団は **78.2%**。人気帯で切ると効果が大きい。

| 人気帯 | 同人気の平均 | 過小評価集団 | 差 |
|---|---|---|---|
| 1-3番人気 | 83.2% | **86.3%** | +3.1pt |
| **4-8番人気** | 78.4% | **84.2%** | **+5.8pt** |
| **9-15番人気** | 69.1% | **74.9%** | **+5.8pt** |

実装は `features.add_recency_features`、
`segments.overvalued` / `segments.undervalued`。

AUC はほとんど動かない（市場込みモデルで +0.0002）。順位付けは市場が
正しく、ずれているのは値付けだから。**AUCではなく回収率で測る必要がある。**

実装は `features.add_recency_features` と
`segments.overvalued_after_last_race`。

## 5. 単勝の支持率と的中率

単勝オッズの逆数をレース内で正規化したもの（控除率を除いた**支持率**）は、
その馬に賭けられた金額の割合で、市場の勝率の見積もりそのもの。

| 支持率 | 単勝オッズ（中央値） | 実際の勝率 | 勝率÷支持率 | 単勝回収 | 複勝回収 |
|---|---|---|---|---|---|
| 〜1% | 166倍 | 0.36% | **0.71** | 51% | 56% |
| 1〜2% | 56倍 | 1.37% | 0.94 | 75% | 76% |
| 3〜5% | 21倍 | 4.08% | 1.04 | 83% | 80% |
| 10〜15% | 6.5倍 | 12.2% | 0.99 | 79% | 80% |
| 30〜50% | 2.2倍 | 37.1% | 0.98 | 78% | 86% |
| 50%〜 | 1.4倍 | 60.1% | 1.05 | 84% | 94% |

（全期間 78.8万頭）

- **勝率は支持率でほぼ正しく見積もられている。** 例外は支持率1%未満の大穴で、
  実際の勝率は支持率の7割しかない（大穴の買われすぎ）。
- 複勝回収率は人気馬ほど高い（大穴56% → 1倍台94%）。

### 勝率→3着内率の換算（Harville）は偏る

| 支持率 | Harville の3着内率 | 実際の3着内率 |
|---|---|---|
| 1〜2% | 5.7% | 7.7% |
| 3〜5% | 14.9% | 17.7% |
| 30〜50% | 81.8% | 71.5% |
| 50%〜 | 94.7% | 87.5% |

人気馬で最大10pt過大、中穴で2〜3pt過小。**市場の3着内率を Harville で出して
モデルと比べると、中穴は「モデルの方が高い」ように見えてしまう。**

代わりに、3着内かどうかを `log(支持率)` とその2乗・3乗、`log(頭数)`、その積で
ロジスティック回帰すると、支持率の帯ごとの誤差は概ね1pt以内に収まる
（2024年までで学習、2025年以降で検証、AUC 0.8198）。
市場の3着内率と比べるときはこちらを使うこと。

### 中穴の「モデルと市場の差」は効かない

Harville を基準にすると、中穴（7〜12番人気）で「モデルが市場より高い馬ほど
よく来る」ように見えた（差の大きい組 15.8%、小さい組 6.8%）。これは Harville が
中穴を低く見積もる偏りを、モデルの手柄と取り違えたもの。

支持率の式で測り直すと、傾向は消える（2025年 / 2026年）:

| 中穴を差で5等分 | 実際の3着内率 | 複勝回収率 |
|---|---|---|
| ① モデルが低い（−3.0pt） | 12.8% / 13.1% | 70% / 79% |
| ③ 中間 | 7.4% / 7.2% | 58% / 55% |
| ⑤ モデルが高い（+2.4pt） | 11.7% / 11.6% | 75% / 85% |

差が +8pt を超える中穴（63頭）は、モデル 25.4% に対して実際 15.9%。

「過大評価でない上位馬を軸に、差の大きい中穴を相手にする」買い方も、
三連複・ワイド・馬連のいずれでも、相手を「差の小さい中穴」や「モデルの次点」に
した場合と比べて良くならなかった（三連複で 62.3% / 70.9%）。

**市場と比べるときは、必ず `market.top3_from_support` を基準にすること。**

## 結論

**市場が知らない情報**は見つかっていない。

- モデルに識別力はある（同じオッズ帯で的中率に差が出る）
- しかしその識別力は既に配当へ織り込まれている
- 穴狙いは逆効果（回収率が下がる）

一方で**市場の値付けの歪み**は見つかった（§4）。規模は小さい（最大+3.9pt）が
統計的に有意で、人気薄に集中している。

さらに優位を広げるには、[`FEATURES.md`](FEATURES.md) の未実装分を試すか、
§4 のような行動バイアスをほかにも探すことになる。

| 観点 | 状況 |
|---|---|
| 馬場状態 × 波乱度 | 90の分析で効果を確認（不良7.42% > 良5.95%） |
| 距離替わり | 未実装。いまは距離の絶対値のみ |
| 馬体重増減 | 未実装。いまは絶対値のみ |
| 芝⇔ダート替わり | 未実装 |
| コース × 枠順バイアス | 未実装 |

ただし、これらも市場が既に見ている可能性は高い。
**市場が構造的に見落とすもの**（反映の遅い情報、計算量の多い相互作用）を
探す方が筋がよい。
